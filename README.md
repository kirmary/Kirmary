# KIRMARY Orbital Website

A bilingual Next.js website built around an interactive 3D orbital product ring, KIRMARY red/blue identity, React Bits SplashCursor, a de-duplicated legacy visual archive, technical documents, projects, brands, contact information and an RFQ workflow.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

The approved KIRMARY hydrant image was not present in the supplied archive, so the site intentionally uses a branded CSS placeholder. Replace the single `hydrantImage` constant in `lib/site-content.ts` when the final image is available.
